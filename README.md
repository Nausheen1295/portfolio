## How it's built
- **Plain HTML, CSS and JavaScript (ES modules):** no framework and no build step, deployed on GitHub Pages.
- **One source of truth:** `js/data/` holds the projects, labs, profile, certifications and products. The lab map, cards,
  case studies, search, Engineering Journey and NEXA all render from it.
- **Design system:** tokens and components in `css/nexus/`; a living style guide is at `design-system.html`.
- **Accessibility:** 0 axe-core violations on every page in both themes, full keyboard support, visible focus, and
  reduced-motion support.
- **Performance and SEO:** Lighthouse desktop scores 95–100 for performance and 100 for accessibility, best practices and SEO. The site has per-page
  metadata, Open Graph previews, structured data, a sitemap and a custom 404 page.
- **NEXA knowledge base:** `knowledge/portfolio.json` is generated from the project data and each project's README, and
  published with the site. The [NEXA API](https://github.com/Nausheen1295/nexa) (FastAPI, in its own repo) loads it, so a content change reaches NEXA without a redeploy.
- **Tested:** end-to-end browser tests (Playwright) and content guardrail tests; NEXA's 39 backend tests live in its repo.

### Run locally
JavaScript modules need a local server (double-clicking `index.html` won't work):
```bash
npm run serve        # → http://localhost:4173/portfolio/
```

### Tests
```bash
npm run test:data                 # content guardrails (instant)
cd tests && npm install && npm test   # + end-to-end browser tests, using your installed Chrome
```

### Editing content
- **Projects / labs:** `js/data/projects.js`. Add only verified facts; leave unknown fields `null` and the site shows "not documented yet".
- **Certifications:** `js/data/certificates.js` (newest first). Put the image and PDF in `assets/certificates/`.
- **Products:** `js/data/store.js`. Items stay `planned` until they have a price and an https buy link.
- **Avatar:** add an illustrated image to `assets/` and set `avatar` in `js/data/profile.js`.
- **After changing content:** run `npm run knowledge` (NEXA knowledge), `npm run sitemap`, and `npm run preloads` if you added or removed JS modules.

### Publishing
GitHub Pages serves the `main` branch root (`.nojekyll` serves files as-is). Commit, push, and the site updates within a minute or two.
