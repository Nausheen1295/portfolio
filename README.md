# 🌸 My Portfolio Website

A fully interactive, responsive personal portfolio with a **light-pink theme**, **dark/light mode**, live **GitHub projects**, a **products shop**, a **services** section, and a **blog you can write posts in** (saved in your browser).

## 🚀 How to run it
Just open `index.html` in any browser. That's it — no installation needed.

> Tip: for the GitHub projects to load live data, you must be online and set your username (see below).

## ✨ Features
- 🌗 **Dark / Light mode** toggle (remembers your choice)
- 🩷 Light-pink theme with animated gradient blobs
- ⌨️ Typing animation, scroll-reveal, animated counters & skill bars
- 🐙 **Live GitHub projects** with search
- 🛍️ Products shop + 💼 Services sections
- ✍️ **Blog** — write & delete posts, saved in your browser (localStorage)
- 📬 Contact form (opens your email app — no server needed)
- 📱 Fully responsive + mobile menu
- ♿ Respects reduced-motion preferences

## 📁 Files
- `index.html` — structure & content
- `styles.css` — all styling & themes
- `script.js` — all interactivity
